# Ricardo Transportes — HTML, CSS e JavaScript

Abra index.html no navegador para visualizar. Para publicar, envie todos os arquivos desta pasta à pasta pública da hospedagem, mantendo assets/.

Não precisa instalar Node.js, React, dependências ou executar uma compilação.

Arquivos:
- index.html: conteúdo, estrutura, metadados e ícones SVG originais.
- styles.css: CSS estático gerado dos estilos do código-fonte original, incluindo os pontos de adaptação para celular e computador. Não depende de Tailwind no navegador.
- script.js: menu móvel, cabeçalho ao rolar, animações de entrada e ano do rodapé.
- assets/hero-van.jpg: imagem original, sem alteração de qualidade.

Foram preservados os textos, links, imagem, ícones, medidas e classes da página React. O mapa incorporado depende do Google e de conexão com a internet. O endereço de Facebook continua sendo o endereço genérico presente no projeto original.

Referência: código-fonte src/ do ZIP. A pasta .output/ contém uma compilação diferente do código-fonte (por exemplo, 93,75% no tamanho da fonte desktop, enquanto src/styles.css define 110%). A conversão segue o código-fonte mais recente fornecido.

Verificação: estrutura estática e lógica do menu, cabeçalho, animações e ano verificadas automaticamente. A comparação visual no navegador em diferentes larguras não pôde ser concluída neste ambiente; a fidelidade pixel a pixel ainda precisa dessa conferência.
